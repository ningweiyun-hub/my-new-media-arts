# 玻璃花窗：聽得見的碎裂

新媒體藝術全景課　作品四「音像互動」的創作歷程網頁。

- OpenProcessing：https://openprocessing.org/sketch/3057957
- 網頁：`index.html`

## 資料夾

```
index.html            網頁本體
assets/moodboard/     靈感圖
assets/process/       每個版本的錄影和截圖
assets/final/         最終的 10 張靜態圖
```

## 圖片檔案

情緒板的圖都在 `assets/moodboard/`，來源是 Pinterest，網頁圖說附了原 pin 的連結。
10 張靜態圖在 `assets/final/still_01.jpg` 到 `still_10.jpg`，只要檔名對，網頁會自動顯示。

## 用 GitHub Pages 上線

1. 在 GitHub 開一個新的 repository，例如 `glass-window`
2. 把這個資料夾裡的所有檔案上傳（Add file → Upload files）
3. Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`，按 Save
4. 等一兩分鐘，網址會是 `https://ningweiyun-hub.github.io/glass-window/`
