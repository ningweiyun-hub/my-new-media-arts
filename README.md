# 玻璃花窗：聽得見的碎裂

新媒體藝術全景課　作品四「音像互動」的創作歷程網頁。

- OpenProcessing：https://openprocessing.org/sketch/3057957
- 網頁：`index.html`

## 資料夾

```
index.html            網頁本體
assets/moodboard/     靈感圖
assets/process/       每個版本的錄影和截圖
assets/final/         最終的 10 張靜態圖
```

## 圖片檔案

情緒板的圖都在 `assets/moodboard/`，來源是 Pinterest，網頁圖說附了原 pin 的連結。
10 張靜態圖在 `assets/final/still_01.jpg` 到 `still_10.jpg`，只要檔名對，網頁會自動顯示。
